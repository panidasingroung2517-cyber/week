# ร้านหนังสือออนไลน์ “Chot Thean” (โชติเทียน) 📚✨

เว็บแอปพลิเคชันร้านขายหนังสือออนไลน์แบบครบวงจร รองรับการใช้งานอย่างสมบูรณ์แบบบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Responsive Web App) ออกแบบสไตล์ **Modern, Minimal & Premium Book Store** 

---

## 🌟 ฟีเจอร์หลัก (Features)

### 👤 ส่วนของลูกค้า (Customer Experience)
1. **หน้าแรก (Home & Hero Showcase)**:
   - แสดงหนังสือแนะนำประจำสัปดาห์ (Featured)
   - หนังสือใหม่มาแรง (New Arrivals)
   - หนังสือขายดี (Bestsellers)
   - แบนเนอร์โปรโมชันพร้อมปุ่มคัดลอกโค้ดส่วนลดใน 1 คลิก (`WELCOME50`, `FREESHIP`, `CHOTTHEAN15`)
2. **ระบบค้นหาและกรองหนังสือ (Search & Filtering)**:
   - ค้นหาแบบเรียลไทม์ตามชื่อเรื่อง, ผู้แต่ง, หมวดหมู่ และ ISBN
   - กรองตามหมวดหมู่: นิยาย, การ์ตูน/มังงะ, หนังสือเรียน, พัฒนาตนเอง, หนังสือเด็ก
   - กรองตามรูปแบบ: หนังสือเล่ม (Physical), E-Book (Digital), หรือทั้งสองแบบ
   - จัดเรียงตาม: แนะนำ, คะแนนรีวิวสูงสุด, ปีที่ตีพิมพ์, ราคาต่ำ-สูง, ราคาสูง-ต่ำ
3. **หน้ารายละเอียดหนังสือ (Book Detail)**:
   - ภาพปกหนังสือ, เรื่องย่อ, ชื่อผู้แต่ง, สำนักพิมพ์, ภาษา, จำนวนหน้า, ปีที่ตีพิมพ์
   - ระบบสลับเลือกซื้อระหว่าง "หนังสือเล่ม" หรือ "E-Book"
   - คะแนนดาวและรีวิวจากผู้อ่าน พร้อมตราสัญลักษณ์ผู้ซื้อจริง (Verified Purchase)
   - ปุ่มทดลองอ่านบทตัวอย่าง (Free Sample Reader)
4. **ตะกร้าสินค้า (Cart Drawer)**:
   - สไลด์ถาดตะกร้าจากด้านขวา สะดวกสบาย
   - ปรับจำนวนเล่ม หรือลบรายการได้ทันที
   - แถบแจ้งเตือนสิทธิ์ส่งฟรีเมื่อยอดสั่งซื้อครบ ฿400
   - ช่องใส่โค้ดส่วนลดพร้อมคำนวณยอดสุทธิแบบเรียลไทม์
5. **ระบบ Checkout & ชำระเงิน**:
   - กรอกข้อมูลผู้รับและที่อยู่จัดส่ง
   - รองรับ **พร้อมเพย์ QR Code (PromptPay)** พร้อมระบบจำลองการจ่ายเงินทันที
   - รองรับบัตรเครดิต/เดบิต และเก็บเงินปลายทาง (COD)
   - เอฟเฟกต์เฉลิมฉลอง (Confetti) เมื่อสั่งซื้อสำเร็จ
6. **ระบบติดตามสถานะคำสั่งซื้อ (Order Tracking & Receipt)**:
   - เส้น Timeline แสดง 5 ขั้นตอน: รอตรวจสอบ → ยืนยันออเดอร์ → กำลังแพ็คพัสดุ → จัดส่งแล้ว (พร้อมเลขพัสดุ Flash/Kerry) → สำเร็จ
   - ใบเสร็จรับเงินอิเล็กทรอนิกส์ (E-Receipt) พร้อมปุ่มพิมพ์
7. **ระบบอ่าน E-Book ในตัว (Built-in E-Book Reader)**:
   - **ระบบตรวจสอบการชำระเงินก่อนเข้าถึงไฟล์**: ตรวจสอบสิทธิ์ผู้ซื้อก่อนอนุญาตให้อ่านฉบับเต็ม หากยังไม่ได้ชำระเงินจะแสดงเฉพาะบทตัวอย่างทดลองอ่าน
   - **บันทึกความคืบหน้าขึ้น Cloud Firestore อัตโนมัติ (Reading Progress Sync)**: บันทึกบทและหน้าที่อ่านค้างไว้แบบเรียลไทม์ และเปิดต่อจากจุดเดิมทันทีเมื่อกลับเข้ามาอ่าน (Resume Reading exactly where you left off)
   - แถบแสดงเปอร์เซ็นต์ความคืบหน้าการอ่าน (Progress Bar) และสัญลักษณ์สถานะบันทึกบนคลาวด์
   - ปรับขนาดตัวอักษรได้ 4 ระดับ (A-, A, A+, A++)
   - เปลี่ยนธีมการอ่าน: กระดาษถนอมสายตา (Paper), ซีเปียวอร์ม (Sepia), โหมดมืด (Dark)
   - สลับบทและดาวน์โหลดไฟล์สำหรับอ่านออฟไลน์
8. **สิ่งที่อยากได้ (Wishlist) & ชั้นหนังสือของฉัน (My E-Books)**:
   - บันทึกหนังสือเล่มโปรด
   - ชั้นหนังสือดิจิทัลส่วนตัว รวบรวม E-Book ทั้งหมดที่เคยสั่งซื้อ พร้อมแถบแสดงเปอร์เซ็นต์ที่อ่านถึงและปุ่ม "อ่านต่อจากจุดเดิม (บทที่ X)" ทันที
9. **ระบบรีวิวและให้คะแนน (Reviews & Ratings)**:
   - ให้คะแนน 1-5 ดาว พร้อมพิมพ์หัวข้อและความคิดเห็น
10. **ระบบแจ้งเตือน (In-App Notifications)**:
    - แจ้งเตือนเมื่อสถานะคำสั่งซื้อเปลี่ยน, มีหนังสือใหม่, หรือมีโค้ดส่วนลด

### 🛡️ ส่วนของผู้ดูแลร้านและแคชบอร์ด (Admin Backoffice & Cashboard)
1. **แคชบอร์ด & การเงิน (Cashboard & Cashflow Analytics)**:
   - ตรวจสอบยอดเงินสดรับรวม (Gross Cash Inflow) แบบเรียลไทม์
   - สรุปกระแสเงินสดแยกตามช่องทาง: พร้อมเพย์ QR, บัตรเครดิต, และเก็บเงินปลายทาง (COD)
   - กราฟแท่งแสดงแนวโน้มยอดขายรายวันตลอดสัปดาห์ (Cashflow Timeline)
   - ยอดขายเฉลี่ยต่อออเดอร์ (AOV) และกำไรขั้นต้นประมาณการ (~45%)
   - สรุปการกระทบยอดเงินสด (Cash Settlement Sheet) พร้อมปุ่มพิมพ์รายงาน
2. **เครื่องคิดเงินหน้าร้าน / แคชเชียร์ POS (Point of Sale Counter)**:
   - ค้นหาและคลิกเลือกหนังสือเพื่อออกบิลคิดเงินสำหรับลูกค้าหน้าร้านหรือสั่งซื้อทางโทรศัพท์
   - เครื่องคำนวณเงินรับและเงินทอนอัตโนมัติ (Cash Tendered & Change Calculator)
   - บันทึกการขาย ตัดสต็อกลงระบบ และพิมพ์สลิปใบเสร็จรับเงิน POS ได้ทันที
3. **บอร์ดคำสั่งซื้อ (Order Pipeline Kanban)**:
   - แสดงคอลัมน์ขั้นตอนงานแบบคันบัง: รอตรวจสอบชำระ ➔ ยืนยันแล้ว ➔ กำลังแพ็ค ➔ จัดส่งแล้ว ➔ สำเร็จ
   - เลื่อนสถานะงานได้ใน 1 คลิก พร้อมโมดอลใส่หมายเลขพัสดุและพิมพ์ใบเสร็จ
4. **จัดการหนังสือ (Book Catalog Management)**:
   - เพิ่มหนังสือใหม่ (รองรับปก URL, เนื้อหา E-Book, บทตัวอย่าง, ราคา, หมวดหมู่)
   - แก้ไขข้อมูลหนังสือ
   - ลบหนังสือ (เฉพาะสิทธิ์ Admin)
   - ปุ่มปรับสต็อกด่วน +/- 1 เล่ม
5. **จัดการคำสั่งซื้อ (Orders Table Management)**:
   - อัปเดตสถานะออเดอร์ (Pending → Confirmed → Processing → Shipped → Delivered → Cancelled)
   - ใส่หมายเลขพัสดุ (Tracking Number) เพื่อแจ้งเตือนลูกค้า
6. **จัดการสต็อกสินค้า (Inventory Control)**:
   - กรองเฉพาะหนังสือที่สต็อกใกล้หมด (≤ 5 เล่ม)
   - ปุ่มเติมสต็อกด่วน +10 เล่ม, +50 เล่ม
7. **จัดการหมวดหมู่ (Category Management)**:
   - เพิ่มหมวดหมู่หนังสือ พร้อม slug และคำอธิบาย
8. **จัดการโปรโมชันและคูปอง (Coupons & Discounts)**:
   - สร้างโค้ดส่วนลด (แบบจำนวนเงินคงที่ ฿ หรือแบบเปอร์เซ็นต์ %)
   - กำหนดยอดสั่งซื้อขั้นต่ำ และวันหมดอายุ
   - สลับเปิด/ปิดการใช้งานโค้ดได้ทันที
9. **จัดการและกลั่นกรองรีวิว (Review Moderation)**:
   - ตรวจสอบรีวิวจากลูกค้า
   - อนุมัติ หรือซ่อนรีวิวที่ไม่เหมาะสม
10. **ระบบสิทธิ์ผู้ใช้งาน (RBAC - Role-Based Access Control)**:
    - แบ่งสิทธิ์เป็น **Admin**, **Staff**, และ **Customer**
    - มี **Demo Role Switcher** ที่แถบบนสุดและหน้าโปรไฟล์ เพื่อให้ผู้ทดสอบสามารถสลับบทบาททดลองใช้งานได้ทันที
    - กำหนดให้ `panidasingroung2517@gmail.com` เป็นผู้ดูแลระบบหลัก (Bootstrap Admin)
11. **ระบบซิงค์ Firestore ใน 1 คลิก (One-Click Firestore Sync)**:
    - ปุ่มซิงค์ข้อมูลหนังสือตัวอย่างทั้ง 21 รายการ หมวดหมู่ และคูปองขึ้นสู่ Cloud Firestore ทันที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide React Icons
- **Animation**: Canvas Confetti, CSS Transitions
- **Authentication**: Firebase Authentication (Google Sign-In & Demo Switcher)
- **Database**: Cloud Firestore (พร้อม Security Rules ป้องกันการเจาะระบบ)
- **Rules Deploy**: `firestore.rules` ตามมาตรฐานความปลอดภัยสูงสุด (ABAC & Principle of Least Privilege)

## ☁️ วิธีการตั้งค่า Firebase (Firebase Setup Guide)

### 1. สร้างโปรเจกต์ใน Firebase Console
1. ไปที่ [Firebase Console](https://console.firebase.google.com/)
2. กด **Create a project** แล้วตั้งชื่อโปรเจกต์ เช่น `chot-thean-bookstore`

### 2. เปิดใช้งาน Firebase Authentication
1. เมนูด้านซ้ายเลือก **Authentication** > กด **Get Started**
2. ในแท็บ **Sign-in method** ให้กดเปิดใช้งาน **Google**
3. บันทึกการตั้งค่า

### 3. เปิดใช้งาน Cloud Firestore
1. เมนูด้านซ้ายเลือก **Firestore Database** > กด **Create database**
2. เลือกโหมด **Production mode** และเลือก Region (เช่น `asia-southeast1` หรือใกล้เคียง)

### 4. ติดตั้ง Security Rules
คัดลอกเนื้อหาจากไฟล์ `firestore.rules` ในโปรเจกต์นี้ ไปวางในแท็บ **Rules** ของ Cloud Firestore แล้วกด **Publish**

หรือใช้คำสั่ง Firebase CLI:
```bash
npm install -g firebase-tools
firebase login
firebase init firestore
firebase deploy --only firestore:rules
```

## 🚢 วิธีการ Deploy ขึ้น Production

### ทางเลือกที่ 1: Deploy บน Firebase Hosting
```bash
npm run build
firebase init hosting
# เลือกระบุโฟลเดอร์ public directory เป็น 'dist'
# ตอบ Yes สำหรับ Single-page app (rewrite all urls to /index.html)
firebase deploy --only hosting
```

### ทางเลือกที่ 2: Deploy บน Vercel หรือ Cloud Run
- เพียงเชื่อมต่อ GitHub Repository กับ Vercel หรือ Google Cloud Run
- คำสั่ง Build: `npm run build`
- ไดเรกทอรีผลลัพธ์: `dist`

## 📚 รายการหนังสือตัวอย่าง (21 รายการ)
ระบบมาพร้อมหนังสือตัวอย่างคุณภาพสูงครอบคลุมทุกหมวดหมู่ ได้แก่:
1. **นิยาย & วรรณกรรม**: ความทรงจำที่โปรยปรายในฤดูใบไม้ผลิ, ปาฏิหาริย์ร้านชำของคุณนามิยะ, ฆาตกรรมปิดตายบนเกาะภาพลวงตา, เจ้าชายน้อย
2. **การ์ตูน & มังงะ**: ดาบพิฆาตอสูร, Solo Leveling, SPY x FAMILY, มหาศึกคนชนเทพ
3. **หนังสือเรียน & เตรียมสอบ**: TGAT 1-2-3 รวมแนวข้อสอบ, Essential Grammar in Use, A-Level ชีววิทยา, ตะลุยโจทย์ TPAT 3
4. **พัฒนาตนเอง & ธุรกิจ**: Atomic Habits, จิตวิทยาว่าด้วยเงิน, คิดแบบยิว ทำแบบญี่ปุ่น, เมื่อลมหายใจกลายเป็นอากาศ, กลยุทธ์สร้างคอนเทนต์ให้ทะลุล้านวิว, นิทานปรัชญาเซน
5. **หนังสือเด็ก & นิทาน**: นิทานดาวดวงน้อยและเพื่อนในป่าใหญ่, ลูกหมูสามตัวกับบ้านขนมหวาน, นิทานก่อนนอนเสริมสมาธิ
